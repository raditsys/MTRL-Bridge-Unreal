# Contributing

Bug reports and focused fixes are welcome.

For AI Build issues, include the complete MTRL recipe and exact parser error. For live preview issues, use **Copy error** and include the generated debug report. For Unreal round-trip issues, include the Unreal Engine 5.4.x patch version and a minimal copied-node example when possible.

Please keep pull requests focused. The browser application intentionally remains self-contained in `index.html`; avoid adding a build system or runtime dependency unless it solves a clear limitation.
